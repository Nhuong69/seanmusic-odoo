# Tài sản nguồn

- `branding/`: logo nguồn của dự án.
- `products/originals/`: toàn bộ thư mục `Sale/` cũ, giữ tên gốc để không mất đối chiếu.
  Đây là ảnh dự án cung cấp, không mặc nhiên là bằng chứng còn tồn hàng.
- `products/references/`: thư mục `asset/store_product_images/` cũ; manifest giữ
  `page`, `url`, `file`, chỉ đổi đường dẫn file theo cấu trúc mới.
- `products/services/`: ảnh dịch vụ từ `asset/product_services/` cũ.

Ảnh web được đóng gói trong `custom_addons/*/static/src/img/`. Ảnh chụp nghiệm thu
ở `artifacts/redesign-preview/` là baseline lịch sử, không chứng minh trang hiện tại.
Không đồng nhất ảnh hãng với ảnh món hàng cũ cụ thể; cần quyền sử dụng trước khi public.
